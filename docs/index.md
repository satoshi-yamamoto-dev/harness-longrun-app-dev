# longrun-app-dev

作りたいWebアプリを文章で伝えると、仕様の作成、コードの実装、ブラウザでの動作確認を順に行うClaude Code Pluginです。評価で見つかった問題は、設定した費用・時間・評価回数の上限内で修正します。

## できること

| 機能 | 内容 |
| --- | --- |
| 仕様の作成 | 要求を整理し、機能と確認項目をまとめます |
| アプリの実装 | 仕様に沿って対象プロジェクトのコードを作成・変更します |
| ブラウザでの評価 | 実装担当とは別のエージェントがアプリを操作し、動作と画面を確認します |
| 修正と再評価 | 評価で問題が見つかると、残りの予算内で修正と評価を繰り返します |
| 結果の保存 | 仕様、実装・評価レポート、画面の証跡、使用量を保存します |
| 停止・再開 | 実行の停止を要求し、保存された区切りから残りの予算で再開できます |

## 実行の流れ

1. **Planner：仕様を作る** — 何を作り、何を確認するかを整理します。
2. **Generator：実装する** — 仕様に沿ってアプリを実装します。
3. **Evaluator：動作を確認する** — アプリを起動し、ブラウザで操作して評価します。
4. **完了、または修正する** — 評価を通過すれば完了です。問題があれば上限内で実装に戻ります。

この一連の実行を「Run」と呼びます。RunごとにIDが付き、結果を後から確認できます。上限に達した場合は、評価が未完了でも停止します。

## 利用する環境

Claude Code、Node.js 24以上、Git、対象アプリのパッケージ管理ツールが必要です。ブラウザ評価にはPlaywright MCPとブラウザも用意します。クイックスタートではWindowsとMicrosoft Edgeを使います。

対象はローカルで起動できるWebアプリです。Runは専用のGitブランチで作業し、実装の区切りをコミットします。生成したアプリの公開は、完成後に利用者が行います。

現在は開発中です。最初は小さな要求で試し、設定する費用・時間上限を確認してください。
