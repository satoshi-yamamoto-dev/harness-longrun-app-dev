# longrun-app-dev

短いアプリ要求から仕様を作り、実装と独立した動作評価を反復するClaude Code Pluginです。現在は開発・実利用検証段階です。

- [導入・更新・復元手順](setup.md)
- [開発者向けガイド](developer-guide.md)
- [開発計画と暫定完了の記録](development-plan.md)
- [今回の試験結果と実利用での確認事項](reviews/provisional-validation.md)
- [要件定義](requirements.md)

まず専用のローカルプロジェクトで、モデルと費用・時間上限を設定して利用してください。公開先へのpushやデプロイは、このPluginのRunとは別に行います。
